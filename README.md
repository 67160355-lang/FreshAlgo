# 🍃 FreshAlgo — Smart Harvesting & AI Fruit Sorting System

> **Precision in Every Pick, Perfection in Every Bite**
> *Smarter Data · Greener Tomorrow*

FreshAlgo คือแนวคิดธุรกิจระบบ **เก็บเกี่ยวและคัดแยกผลไม้อัจฉริยะ** ที่ใช้กล้อง AI และเซนเซอร์อินฟราเรดตรวจผลไม้แบบ **Non-Destructive** (ไม่ต้องผ่า) เพื่อลดการถูกตีกลับของสินค้าส่งออก เพิ่มความเร็วในการคัดเกรด และการันตีความหวาน (Brix) ทีละลูก

ชื่อมาจาก **Fresh** (ความสดใหม่ของผลผลิต) + **Algo** (Algorithm / ระบบ AI และความแม่นยำ)

## 🎯 ปัญหาที่แก้ (Pain Points)

| กลุ่มลูกค้า | ปัญหาหลัก |
|---|---|
| **ผู้ส่งออกผลไม้พรีเมียม** | สินค้าโดนตีกลับจากหนอน / เนื้อเป็นซ้ำ / เน่าภายในที่ตามองไม่เห็น กระทบชื่อเสียงแบรนด์และเสี่ยงโดนแบนในต่างประเทศ |
| **ชาวสวน / เจ้าของแปลงใหญ่** | วิกฤตแรงงาน (สังคมสูงวัย แรงงานต่างด้าวหายาก ค่าแรงสูง) · ผลไม้ช้ำหรือเก็บอ่อน/แก่เกินไป · คาดการณ์รายได้ไม่ได้จนกว่าจะเก็บเสร็จ |
| **สหกรณ์การเกษตร / วิสาหกิจชุมชน** | เข้าไม่ถึงเทคโนโลยีราคาสูง · ต้องขาย "ข้าวคละเกรด" ให้พ่อค้าคนกลางแบบโดนกดราคา |

## 💡 Value Proposition

- แก้ปัญหาสินค้าโดนตีคืน (เป้าหมาย **0%**)
- คัดมาตรฐานโดยไม่เสียหาย วัด Brix และความสุกแก่ทีละลูก
- ทะลุขีดจำกัดด้านเวลา — คัดเกรดเร็วขึ้น **3 เท่า**
- ลดการบอบช้ำของผลผลิต
- เข้าถึงเทคโนโลยีระดับสูงในราคาจับต้องได้ (Democratizing Technology)
- เพิ่มอำนาจต่อรองด้วยการแยกเกรด A / B / C ที่มีใบรับรองจาก AI

ตัวอย่างป้ายการันตี: *"ทุเรียนพร้อมทานใน 2 วัน"* · *"มะม่วงมหาชนกความหวาน 15 Brix"*

## 🧩 โมเดลธุรกิจ

### Customer Segments
1. **Premium Exporter** — ผู้ส่งออกผลไม้พรีเมียม เน้นเครื่องคัดแยก AI ความเร็วสูง
2. **Large Orchard** — แปลงใหญ่ / เกษตรกรอุตสาหกรรม เน้นเครื่องเก็บเกี่ยวอัตโนมัติ
3. **Agricultural Co-op** — สหกรณ์และวิสาหกิจชุมชน เน้นบริการคัดแยกส่วนกลาง
4. **Service Startup** — ผู้ให้บริการรับจ้างเก็บเกี่ยว ซื้อ/เช่าเครื่องไปให้บริการต่อ

### Revenue Streams
| Stream | รายละเอียด |
|---|---|
| **Machine Purchase** | ขายขาดเครื่องเก็บเกี่ยวหรือเครื่องคัดแยกอัจฉริยะ (รายได้ก้อนใหญ่) |
| **Software Subscription** | ค่าสมาชิกซอฟต์แวร์ AI และ Data Analytics รายเดือน/รายปี |
| **SLA Contract** | สัญญาซ่อมบำรุงและตรวจเช็กสภาพเครื่องรายปี |
| **Pay-per-use / Rental** | จ่ายตามการใช้งานจริง หรือเช่า เพื่อลดภาระเงินก้อนแรกของสหกรณ์ |

### Key Elements
- **Key Partners:** ซัพพลายเออร์กล้อง/เซนเซอร์ · นักพัฒนา AI/SW · โรงงานประกอบเครื่องจักร · สถาบันการเงินและภาครัฐ
- **Key Activities:** วิจัยและพัฒนา AI/Computer Vision · ออกแบบเครื่องจักร · การตลาด B2B · บริการหลังการขาย
- **Channels:** ขายตรง B2B · งานแสดงสินค้าเกษตรและเทคโนโลยี · เครือข่ายพันธมิตร · เว็บไซต์/โซเชียล
- **Customer Relationships:** ดูแลใกล้ชิดด้วยทีมวิศวกร · Co-creation กับเจ้าของแปลง · อัปเดต AI ต่อเนื่อง

## 📊 Data Storytelling Dashboard

Dashboard เล่าเรื่องตาม Customer Journey แบ่งเป็น 3 องก์

### ACT 1 — The Problem & Operational Excellence
- **KPI:** Total Volume Sorted · Avg Sorting Speed · Labour Hours Saved
- **Visual:** Bar Chart เปรียบเทียบ Manual vs FreshAlgo AI · Donut Chart ประเภท Internal Defect ที่ Infrared ตรวจพบ · Stacked Bar Defect แยกตามผลไม้

### ACT 2 — Value Creation & Quality Guarantee
- **KPI:** Export Rejection Rate (เป้า 0%) · High-Brix Rate · Grade A Premium Export
- **Visual:** Histogram การกระจายตัวของ Brix ตามชนิดผลไม้ · Stacked Bar เกรด A / B / Reject พร้อมป้ายการันตี

### ACT 3 — Business Model & Monetization Success
- **KPI:** Total Revenue Generated · Active Co-ops · Recurring Revenue Share
- **Visual:** Treemap รายได้ (Stream → Segment) · Grouped Bar กลุ่มลูกค้า × รูปแบบรายได้

### ฟีเจอร์การใช้งาน
- **Filter:** ชนิดผลไม้ · Segment ลูกค้า · ช่วงวันที่
- **เกณฑ์ High-Brix ปรับได้** แยกตามชนิดผลไม้ (ค่าเริ่มต้น ทุเรียน 14 / มะม่วงมหาชนก 15 / มังคุด 16)
- **Toggle Switch:** Operational View (Act 1–2) ↔ Executive/Revenue View (Act 3)
- **Callout Box:** สรุป Key Insight ประจำแต่ละส่วน อัปเดตตาม Filter
- **ตัวเลือก Treemap:** ติ๊ก "ไม่รวมขายเครื่อง" เพื่อดูสัดส่วน Recurring Revenue

## 🗂 ชุดข้อมูล (Dataset)

`FreshAlgo_Mockup_Dataset.csv` — ข้อมูลจำลอง **800 batches** ช่วง **1 ต.ค. 2025 – 30 ก.ย. 2026** จาก 32 ลูกค้า

| คอลัมน์ | ความหมาย |
|---|---|
| `Batch_ID`, `Date_Time` | รหัสและเวลาของแต่ละ batch |
| `Customer_Segment`, `Customer_Name` | กลุ่มและชื่อลูกค้า (4 กลุ่ม) |
| `Fruit_Type` | Durian · Mango (Mahachanok) · Mangosteen |
| `Total_Weight_KG` | น้ำหนักรวมที่คัดแยก |
| `Sorting_Speed_Units_Min` | ความเร็วคัดแยก (ลูก/นาที) |
| `Brix_Value` | ค่าความหวาน |
| `Internal_Defect_Detected` | ตรวจพบความเสียหายภายใน (Yes/No) |
| `Final_Grade` | Grade A (Premium Export) · Grade B (Local Market) · Reject |
| `Rejection_Status` | Passed · Rejection Risk Defected |
| `Pricing_Model` | Machine Purchase · Software Subscription · SLA Contract · Pay-per-use/Rental |
| `Revenue_THB` | รายได้ (บาท) |
| `Labor_Hours_Saved` | ชั่วโมงแรงงานที่ประหยัดได้ |

**ภาพรวม (ค่าเริ่มต้น ไม่กรอง):** ≈ 4,723 ตัน · รายได้ ≈ ฿40.9 ล้าน · ประหยัดแรงงาน ≈ 75,806 ชั่วโมง · ตรวจพบ defect 59 batch (7.4%)

## ⚠️ สมมติฐานและข้อจำกัด

ข้อมูลเป็น **Mock Data** เพื่อการนำเสนอแนวคิด ตัวเลขทั้งหมดไม่ใช่ผลการทดสอบจริง และ Dashboard ใช้สมมติฐานดังนี้

- **Manual vs AI:** CSV ไม่มีข้อมูลแรงงานคน จึงกำหนด Manual = ความเร็ว AI ÷ 3 ตามคำมั่น "เร็วกว่า 3 เท่า"
- **ประเภท Defect:** CSV ระบุแค่ พบ/ไม่พบ การแบ่ง หนอน / เนื้อเน่า / เนื้อเป็นซ้ำ ใน Dashboard เป็น **ข้อมูลจำลอง** (ประมาณ 40 / 35 / 25%)
- **Export Rejection = 0%:** ถือว่า batch ที่เซนเซอร์ตรวจพบ defect ถูกคัดออกก่อนส่งออกทั้งหมด
- **High-Brix:** เกณฑ์ต่อชนิดผลไม้เป็นค่าตั้งต้นที่กำหนดเอง ปรับได้ใน Dashboard
- **Active Co-ops:** นับจำนวนสหกรณ์ที่มี batch เพราะข้อมูลไม่มีจำนวนเกษตรกรรายย่อย
- **ภาพ Hero:** เป็นภาพประกอบ SVG ไม่ใช่ภาพถ่ายจริง
